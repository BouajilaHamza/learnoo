Avant de nous rejoindre

Est-ce que la plateforme est déjà disponible ?

Pas encore. Cette page est un aperçu local et la leçon liée est un exemple technique non relu. La plateforme destinée aux élèves reste à construire.

Les cours seront-ils gratuits ?

Oui. Learnoo prévoit un accès gratuit pour les élèves, avec un compte pour consulter les cours complets et retrouver leurs favoris. L’inscription n’est pas encore disponible.

Comment suivre le projet ?

Consultez le dépôt GitHub pour le code, les décisions et les tâches. Retrouvez aussi la chaîne YouTube Learnoo.
